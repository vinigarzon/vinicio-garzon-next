# ⚡ Quick Start - 5 Minutos

Si solo quieres que funcione **ahora mismo**, sigue esto:

## 1. Instala Node.js (si no lo tienes)

Descarga en https://nodejs.org/ (versión LTS)

Verifica en terminal:
```bash
node --version
npm --version
```

## 2. Descarga el Proyecto

**Opción A: Con Git**
```bash
git clone https://github.com/TU-USUARIO/vinicio-garzon-next.git
cd vinicio-garzon-next
```

**Opción B: Descarga el ZIP**
1. Descarga el archivo ZIP
2. Descomprimelo
3. Abre terminal en esa carpeta

## 3. Instala Dependencias

```bash
npm install
```

## 4. Corre Localmente

```bash
npm run dev
```

Abre: **http://localhost:3000**

## ✅ ¡Listo!

Tu sitio está funcionando.
